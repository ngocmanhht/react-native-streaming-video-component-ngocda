# react-native-streaming-video-component-ngocda

A high-performance, professional-grade streaming video component for React Native, powered by **Nitro Modules**. Designed specifically for low-latency **HLS** and **RTSP** streams with a beautiful, responsive UI.

## 🚀 Features

- ⚡ **Nitro Modules Powered:** Blazing fast native communication for smooth playback.
- 📹 **Protocol Support:** Comprehensive support for HLS (.m3u8) and RTSP streams.
- 🎨 **Premium UI:** Built-in responsive video controls with a modern aesthetic.
- 📱 **Cross-Platform:** Consistent experience across iOS (AVPlayer) and Android (ExoPlayer).
- 🛠 **Customizable:** Easily adjust resize modes, playback controls, and more.
- 📸 **Frame Capture:** Built-in support for taking high-quality screenshots of the stream.

## 🏗 Development

If you are contributing to this library or using it as a local dependency:

1. **Install dependencies:**
   ```bash
   npm install
   ```

2. **Generate Nitro code:**
   ```bash
   npm run codegen
   ```

3. **Build the library:**
   ```bash
   npm run prepare
   ```
